# Bottie 0.9.0 beta

Version: 0.9.0
Channel: beta

Bottie 0.9.0 is the first tester-facing desktop beta candidate. It is intended for informed beta testing, not broad
end-user distribution. Publication remains conditional on Bottie's release-candidate manifest passing every platform,
signing, notarization, artwork, dependency, licence, and notice gate.

## What is ready for testing

- Local oMLX and Ollama plus explicit OpenAI-compatible and Anthropic-compatible providers.
- Durable, searchable, branch-aware conversations with ratings, export, verified backup, restore, and recovery.
- Bounded image and document attachments with native extraction, normalization, preview, and portable export behavior.
- Opt-in hybrid memory, inspectable citations, and per-conversation exclusion, Trash retention, and permanent forget.
- Opt-in native clock, Web search/fetch, and read-only Localmail tools with durable audit and strict native boundaries.
- First-run privacy setup, themes and density, keyboard commands, reduced-motion support, diagnostics export, and
  long-history performance budgets.

## Beta cautions

- Back up important conversations before testing a new build and before moving between beta versions.
- Local and cloud model behavior depends on each configured provider and model capability.
- Web and Email tools send the displayed bounded context to the selected provider only when explicitly enabled.
- EmbeddingGemma model files are downloaded on first semantic-index use from one hash-verified immutable revision and
  remain subject to the bundled model notice, the Gemma terms, and explicit release-owner acceptance gate.
- The native update client is configured, but no signed updater artifact or manifest has been published; arbitrary
  MCP execution is not included in this beta candidate.

## Distribution status

Do not redistribute an artifact unless its matching `0.9.0` release-candidate manifest reports `ready: true`. A green
source test suite or an unsigned package smoke is not release approval. macOS must be Developer ID signed, notarized,
stapled, and accepted by Gatekeeper; the selected Windows route requires an exact-identity MSIX that passes current
runner packaging and Windows App Certification Kit checks before Microsoft Store certification and signing. Microsoft
rejected the submitted listing's macOS screenshots; certification and publication remain deferred until further
notice from the release owner, and submission is not publication approval. Linux
must carry its required independently verified embedded OpenPGP origin signature. The root project licence, generated
third-party notice bundle, and model notice must match the hashes in that package's evidence; model-terms acceptance is
separate legal evidence and is never inferred from a successful build.

Microsoft rejected the submitted listing because its screenshots showed the macOS build rather than Bottie running
on Windows. Store certification and publication remain deferred until further notice from the release owner; the
prior submission is not certified or published and must not be used as release evidence.

The public certificate, fingerprint, expiry, policy, and Debian verification procedure are documented in
[`distribution/linux/README.md`](../distribution/linux/README.md). Publishing that public trust material does not by
itself mean a signed package has passed the release gate or is approved for redistribution.

The production updater trust and credential-free manifest/evidence contracts are documented in
[`distribution/update/README.md`](../distribution/update/README.md). The recoverably backed-up production key and
Rust-owned check/install UI now exist, but no protected updater artifact, `latest.json`, tag, or release has been
created or published.
