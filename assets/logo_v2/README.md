# Bottie primary logo

`bottie_icon_512.png` is Bottie's project-supplied primary logo and application-icon master. The locked icon pipeline
derives the macOS, Windows, Linux, WebView, and website icon/logo files from this exact source.

The artwork was supplied by the project maintainer on 2026-09-30 for use as Bottie's application icon and general
logo. It is project-owned and distributed with Bottie under the repository's MIT licence.
