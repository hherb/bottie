# Legacy Bottie logo family

These assets are retained for historical/reference use. Bottie's current primary logo and application-icon master is
[`../logo_v2/bottie_icon_512.png`](../logo_v2/bottie_icon_512.png); new product surfaces should use that artwork or a
locked generated derivative.

The mark combines a geometric **B**, a speech-bubble counter, an orbital sweep, and a coral action spark. It is designed to communicate Bottie's movement from chat interface toward active assistant.

## Files

- `bottie-mark-color.svg` — legacy color mark
- `bottie-icon-512.png` — legacy app/repository icon
- `favicon-64.png` — legacy small browser icon

## Palette

- Indigo: `#2437A5`
- Coral: `#FF675C`
- Dark wordmark: `#172052`
- Dark-mode periwinkle: `#AEB8FF`

Keep clear space around the mark equal to at least half the width of the speech-bubble tail. Do not add gradients, shadows, chat dots, or extra orbital rings.
